# Proposal

## Why
Users need editable library names, visible free-tier generation allowances and lasting self-assessed flashcard progress. The owner also requested an audited administrator grant for an existing account.

## What Changes
- Owner-scoped file and study-set renaming in the library and workspace.
- A 200,000-token default free allowance per UTC calendar month, administrator-editable globally and per user, backend enforcement and percentage-only user meters.
- Persistent flashcard review rounds, correct/incorrect self-assessment, resumable progress, completion summaries and historical improvement.
- Existing persisted study formats and browser drafts remain readable without normalization.

## Impact
Metadata APIs/UI, isolated quota/review persistence, provider usage integration, admin controls, regression checks and deployment. No extra model request or change to mathematical rendering.
